青年诗词网 

这是一个用 HTML 基础标签制作的古诗词介绍网页，包含首页、唐诗、宋词、元曲、登录和注册页面。

创作背景 🌱

这是我第一次尝试使用 AI 辅助编写网页代码，制作一个简易的 Web 界面。通过这次练习，我把课堂学到的 HTML 标签用在诗词展示、页面导航和评论表单中，也积累了第一次制作网页的经验。💻🤖

页面整理内容 ✨

- 保留原有页面内容和整体布局，只做了小幅调整。
- 在适合的位置使用 `<center>` 标签，让部分内容居中显示。
- 使用 `<hr>` 分隔内容；首页联系方式和学院名称放在评论区底部。
- 将首页诗词表格居中并调整宽度，保留原有表格内容。
- 页面练习了标题、段落、链接、列表、图片、表格和表单等 HTML 基础标签。📝
